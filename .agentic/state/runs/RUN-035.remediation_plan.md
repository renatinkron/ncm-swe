# RUN-035 — Remediation Plan

## Findings

NC-1 (minor): `arms.adapter.texts[10]` e `[11]` em bench_l0cond.json são
strings vazias (cosine 0.0) — heldout #4 pedia textos não-vazios.

## Root cause

Não é bug de pipeline: são gerações degeneradas REAIS — o adapter
condensa l0 na cabeça da marginal (probe mostrou probe==shuffle), e
alguns l0 amostrados geram sequências que decodificam vazio após o
corte em EOS. Isso é evidência do veredito negativo, não defeito de
execução.

## Minimal corrective change

Re-executar não muda o dado (seed fixo → mesmos l0 → mesmos vazios).
A correção é tornar a degenerescência explícita em vez de silenciosa:

1. `scripts/bench_l0cond.py`: agregado por braço ganha `n_empty`
   (contagem de textos vazios após corte EOS/PAD).
2. `artifacts/bench_l0cond.json`: adicionar `n_empty` por braço via
   pós-processamento determinístico dos texts já gravados (sem
   re-gerar — os dados são os mesmos).
3. `artifacts/report.md` + `SESSION_HANDOFF.md`: notar que 2/16
   amostras do braço adapter degeneraram a vazio (vs 0/16 unigram) —
   dado consistente com o veredito.
