## Blind-review remediation (cycle 3)

Blind review (2 major): RNG global drenado entre braços (eval não
pareado) + max_length 64 vs 24 na featurização do prefixo. Fix:
reseed por braço em gen_decode + max_len param (24 prefixos / 64
gerados). Minors corrigidos: marginal CE por fatia de eval por braço
(E 7.799 / H 7.801), THREADS honrado no probe, rec_id agora registra
o record onde o segmento COMEÇA (dump).
Bench re-rodado pareado: adapter cos 0.550 / dup 0.194 / dist 0.684 /
n_empty 0 vs unigram cos 0.557 / dup 0.216 / dist 0.563 / n_empty 1 —
empate dentro do ruído (veredito mantido: adapter ≈ marginal).
Limitações registradas: subsample H = primeiras N linhas (ordem do
corpus); adapter escolhido por CE de held-eval.
