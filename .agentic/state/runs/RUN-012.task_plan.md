### T001 — `--target ar` no train_token_head.py

**Intent**: novo flag `--target {truth,ar}` (default truth p/
retrocompat). Com `ar`: logits do backbone congelado na mesma
posição viram o alvo — soft-CE `KL(student || softmax(AR_logits/T))`,
T=1 default (`--temperature`). Logar loss + top1_ar (argmax) +
top1_truth (informativo). Out default `artifacts/token_head_ar_qwen05`
(não clobberar o ckpt truth).
**Domain**: ml | **Risk**: low | **Deps**: []
**Acceptance**: flag funciona; smoke 50 passos roda; loss codes cai
abaixo de ~11,9; eval@N loga ambas as métricas.
