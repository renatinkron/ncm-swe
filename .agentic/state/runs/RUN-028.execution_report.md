# RUN-028 execution report — chunk-local decode

## Implementado (T1)

`src/ncm_swe/model/generator.py`:

- `_gofs` (init): offset global de sequência de cada chunk `[q0]+chunks`.
- `_level_contrib(codes_j, j)` / `_interp_chunk(z_hat, L)`: extraídos de
  `_chunks_from_codes`, permitem z_hat incremental por nível no decode.
- `_forward_chunk(base_chunk, k_next, cur, decided)`: trunk sobre
  `[q0 + chunk do nível]` apenas — atenção block-diagonal torna chunks
  anteriores dead weight (paridade com `vendor/ncm-upstream
  models/next_concept.py` generate). Pos/level/RoPE indexados nas
  posições globais (RoPE é absoluta).
- `generate()` reescrito: ambos os modos (intra e não-intra) + rounds de
  refinement usam `_forward_chunk`; z_hat acumulado incrementalmente.
- `_forward_partial` mantido como referência para testes.
