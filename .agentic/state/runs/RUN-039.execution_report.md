### T4-ext2 — channel vs generator fault isolation (`scripts/_diag_channel.py`) — DONE

  capacity. Generator errors compound on top.

## Verdict (honest)
- Channel repair works: 65.24% → 93.33% held-out recovery (98.33% on the
  lesson distribution).
- Architecture is desktop-viable: ~110 equiv text-tok/s, 137M params,
  ~550MB, decoder ~free.
- **NCM does not yet emit compilable Python**: parse 0/32 best case.
  Primary blocker = channel fidelity ceiling (~93-98% tok) below the
  ~99.9% Python requires; generator fine-level errors are secondary.
- Rejected: top-loss dataset condensation; temperature as fix.
