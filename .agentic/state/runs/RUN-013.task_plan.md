cobre os desconhecidos baratos e entrega a receita acionável.

## Branch Strategy

- decision: `current_branch` (`main`).

## Phases

- Phase 1: T001 ∥ T002 | Phase 2: T003

## Tasks

### T001 — Medir throughput do 30B como data factory

**Intent**: benchmark de geração do Qwen3-Coder-30B-A3B GGUF
(parado) com um prompt de síntese estilo Cosmopedia — mede tok/s
reais sem contenção e valida a estimativa de slice sintético
(1-5M tok/dia) do brief. Servidor NÃO fica rodando: só bench
one-shot com timeout.
**Domain**: ml | **Risk**: low | **Deps**: []
**Acceptance**: tok/s medido + projeção documentada (ou "inviável"
honesto se <500 tok/dia úteis).

### T002 — Verificar disponibilidade dos datasets curados

**Intent**: confirmar presença/tamanho/licença das opções:
TinyStories (HF roneneldan), python-edu/Stack-Edu (HF), MiniPile
(JeanKaddour, 6GB). Sem baixar tudo — metadados + escolha de fatia.
**Domain**: data | **Risk**: low | **Deps**: []
**Acceptance**: tabela dataset × tamanho da fatia necessária ×
licença; recomendação de corpus-alvo concreta.

### T003 — Spec de treino v1 (documento acionável)

**Intent**: `.agentic/research/ncm-closed-scope-training-plan.md` —
a receita final passo a passo: corpus (fontes+mistura), tokenizer
(vocab, comando), modelo (params, arquitetura gen_ncm+decoder
co-treinado), schedule (WSD, épocas ≤4, batch), evals (acceptance
nativo, speedup end-to-end, coerência), estimativas de tempo CPU.
Domínio/vocab parametrizados nas opções do brief (default:
Python-edu + 8k vocab, com alternativa TinyStories).
**Domain**: docs | **Risk**: low | **Deps**: [T001, T002]
**Acceptance**: spec completo o suficiente para abrir a próxima
run de implementação sem nova pesquisa.

## Contract

executor: tok/s 30B medido, tabela de datasets, spec v1 escrito.
tester: estimativas do spec consistentes com tok/s medido; nada
baixado/treinado além do bench one-shot; recomendações citam fontes.
