## Verdict

- Held-out CE 2.83 / top-1 45.8% after ~1.2 epochs of batches — the direct-BPE
  path generalizes fine and gives a clean held-out metric the VQ path lacks.
- BUT generation is still 0/32 parse (argmax and sampled). At ~1.2 epochs of
  budget the direct-BPE path does NOT beat the VQ path's free-running numbers
  (argmax 1/32, constrained 8/32 at VQ-CE 0.98).
- Interpretation: the dominant blocker is the **task shape**, not the code
  channel — training rows are mid-file 128-token slices, so unconditional
  generation produces mid-file continuations that can't `ast.parse` as
  standalone programs (gold rows themselves only reach ~56% channel-only
  parse). VQ-641 is not proven to be the bottleneck.
- Plan B remains viable but needs either equal training depth, a task-aligned
  eval (prefix-completion / row-continuation), or native constrained decoding
  (easier on BPE since logits are directly available — no VQ decode hop).
