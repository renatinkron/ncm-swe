# RUN-021 — Task plan: trabalho acadêmico NCM + repo público

## Objetivo
Transformar o estudo NCM (20 runs, out-30→nov-9/2026) em trabalho acadêmico
ABNT (PT-BR + EN-US, abstract EN), publicar em repo GitHub público novo com
histórico anonimizado de pesquisa, licença de uso exclusivamente acadêmico,
após 2 avaliações científicas + 2 revisões gramaticais ABNT por agentes
independentes sem histórico.

## Pergunta prévia respondida (registro)
"Faz sentido compartilhar?" — SIM: replicação parcial independente do NCM em
hardware comum, curva de speedup crescente com escala medida localmente,
descoberta de bug de inicialização que invalidava vereditos anteriores, e
análise sistemática de falhas — material legítimo de relato técnico/replicação,
ideal para um laboratório com cluster executar o teste decisivo de escala.

## Branch
Decisão: `new_branch` — o trabalho ocorre em repositório NOVO fora do git do
ncm_swe (novo diretório `~/Documents/projects/ncm-local-study`, branch `main`
com histórico datado da pesquisa); no ncm_swe não há branch de código a
integrar — apenas os artefatos de estado `.agentic/` desta run seguem no
branch corrente. Nenhuma branch protegida envolvida.

## Contract

### Scope in
- Documento acadêmico ABNT bilíngue + repositório público GitHub + revisões
  multiagente + sanitização de dados pessoais.
### Scope out
- Novos treinamentos/experimentos; alteração dos artifacts fonte; publicação
  de checkpoints.
### Quality gates
- Toda referência rastreável a fonte verificada; nenhum número sem origem.
- Quatro revisões independentes registradas e achados resolvidos antes do push.
- Zero ocorrências de identificadores pessoais no conteúdo publicado.

- [ ] `paper_pt-br.md` (ou .tex) completo em ABNT (14724/6028/6024/10520/6023)

      `.agentic/reviews/RUN-021-abnt-{1,2}.md` + correções aplicadas
