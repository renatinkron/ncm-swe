# RUN-008 Task Plan — Mimir-1.6B (LCM real) como ground truth

Contexto: `mimir-lcm/Mimir-1.6B` no HF = pesos do LCM two-tower-diffusion
da Meta (repo oficial não publica pesos). É o único modelo-de-conceitos
baixável existente — opera no espaço SONAR (conceito = sentença). Regra
do projeto: código terceiro (clone do repo LCM + fairseq2 + sonar-space)
roda **dentro de container rootless**; runtime com `--network none`.
Servidor 30B do usuário foi parado → ~18GB RAM livres. Modelo fp16 1,6B
(~3,2GB; fp32 ~6,4GB se CPU não aceitar fp16 em algumas ops).

## Branch Strategy

- decision: `current_branch` (`main`).

## Phases

- Phase 1: T001, T002 (paralelos — download ∥ build imagem)
- Phase 2: T003 | Phase 3: T004

## Tasks

### T001 — Download pesos + fonte LCM (host)

**Intent**: `huggingface_hub` no venv → baixar `mimir-lcm/Mimir-1.6B`
(~3GB) para `~/models/mimir-lcm/`. Clonar
`github.com/facebookresearch/large_concept_model` para
`~/Documents/projects/_ext/large_concept_model` (somente fonte — nunca
executado no host).
**Domain**: infra | **Risk**: low | **Deps**: []
**Acceptance**: `model.pt` presente com tamanho esperado; repo clonado;
nada do código terceiro executado no host.

### T002 — Imagem de inferência LCM (rootless podman)

**Intent**: Containerfile em `containers/lcm/` (ou
`scripts/containers/`) — base python:3.11-slim, `pip install` torch-cpu,
`fairseq2`, `sonar-space`, `wtpsplit`, `omegaconf`. Build com rede;
runtime estritamente `--network none`, mounts ro: modelo + repo + script.
**Domain**: infra | **Risk**: low | **Deps**: []
**Acceptance**: `podman build` completa; `podman run --network none`
importa lcm/sonar sem erro (network precisa só no build, não no run).

### T003 — Inferência e medição

**Intent**: script `scripts/lcm_probe.py` (copiado/montado no container):
segmenta prompt em sentenças (SaT/wtpsplit), codifica SONAR, gera
conceitos (two-tower diffusion), decodifica SONAR→texto. Medir:
sentenças/s e tok/s efetivos, RSS, qualidade (amostras de texto para
2-3 prompts, ex. "def fibonacci" e prosa). Fallback: se hf download ou
deps falharem, tentar Mimir-1.6B-Instruct ou reduzir a SONAR+fairseq2
isolado. Persistir `artifacts/lcm_probe.json` + amostras.
**Domain**: ml | **Risk**: med | **Deps**: [T001, T002]
**Acceptance**: pelo menos uma geração ponta-a-ponta registrada (texto
gerado decodificado de conceitos) OU falha documentada com causa;
números de latência/RSS medidos.

### T004 — Comparativo + report

**Intent**: seção em `artifacts/report.md`: Mimir vs nosso NCM 471M —
o que "conceito" significa em cada um (sentença SONAR vs código RVQ por
token), velocidade, qualidade, e a resposta à pergunta "o espaço SONAR
resolve a última milha que nosso codebook não resolveu?".
**Domain**: docs | **Risk**: low | **Deps**: [T003]
**Acceptance**: seção com números medidos; comparação honesta
(mecanismos diferentes explicitados).
