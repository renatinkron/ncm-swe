## Tasks

### T001 — `scripts/ncm_panel.py` (painel renderizador sobre ckpt oficial)
**Intent**: CLI que carrega `artifacts/ncm_official/{tokenizer,generator}.pt` via `NextConceptTransformer` (padrão de `ncm_official_probe.py`) e expõe os knobs: `--l0 {unigram,model,uniform,smooth:ε}`, `--temp --top_k --top_p --cfg`, `--freq --mu --adj` (anti-repetição por nível, via override de `_sample_level` — portar lógica de `eval_shard.pick_tokens`), `--preview` (decode por nível via `decode_multiscales`), `--n`, `--seed`, `--threads`. Métricas por amostra: unicode-fraction, dup-4gram rate, distinct-token ratio, s/sample; saída JSON + textos. Modo `--selftest` que valida helpers sem ckpt.
**Acceptance**: `--selftest` passa; `--help` documenta todos os knobs; smoke n=2 roda no container `lcm-infer` e grava JSON com métricas; nenhum arquivo vendored modificado.

### T002 — `data/lora_dump/knowledge_dump.jsonl` + `scripts/dump_knowledge.py`
**Intent**: dump curado de conhecimento avançado — programação em EN; lógica e texto/redação em EN+PT-BR. Schema `{id, lang, domain, topic, content}` com domains: `algorithms`, `data_structures`, `patterns`, `testing`, `debugging`, `complexity`, `logic`, `argumentation`, `writing`. ≥80 entradas, conteúdo denso (não filler), pt-BR com acentuação correta.
**Acceptance**: `dump_knowledge.py --check` valida schema, cobertura por lang/domain, unicidade de content, e imprime contagens; ≥80 linhas válidas.

### T003 — `tests/test_panel.py` + `tests/test_dump.py`
**Intent**: testes unitários sem ckpt/GPU: helpers de sampling (top-k/top-p/penalties), métricas de texto (dup-4gram, unicode-fraction, distinct ratio), schema/validação do dump (reusa `dump_knowledge` check em fixtures mínimas).
**Acceptance**: `pytest tests/test_panel.py tests/test_dump.py` verde no host (venv `ncm` ou system pytest).

### T004 — `docs/ncm-render-panel.md` (design + limites honestos)
**Intent**: documenta o mapeamento renderizador→NCM (passes=níveis fixos K, samplers, samples=N, "bounces"=CFG/recursão futura), tabela de knobs com ranges medidos no smoke, plano de módulos LoRA (alvo: `c_attn/c_proj` + `lm_head`, hand-rolled sem peft nesta passada; peft como upgrade), limites (ckpt TinyStories ~85M, qualidade prévia, CPU ~1.3 s/sample medido), e próximos passos (treino LoRA sobre dump, early-exit de níveis, CFG com null real).
**Acceptance**: doc existe, toda afirmação quantitativa vem de medição desta sessão ou está marcada como estimativa.
