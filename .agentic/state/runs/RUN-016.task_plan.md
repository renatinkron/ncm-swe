# RUN-016 Task Plan — geração intra-nível por chunks mascarados

## Context (de RUN-014/015, verificado)
NCM nativo ×2.8-3.2 mais rápido mas word-salad. Dois braços
(codebook afunilado, 2× steps) falharam: níveis finos ~uniformes
porque predição paralela pura não pode recuperar bits residuais que
o contexto grosso não contém. Fix: condicionamento intra-nível —
posições decididas carregam emb(código), pendentes emb_mask;
atenção dentro do nível flui decididas→pendentes.
