# RUN-033 task_plan — migrar treinamento para o modelo do colibri?

## Branch

- decision: current_branch — análise + artefatos de pesquisa apenas;
  nenhuma mudança de código, branch nova desnecessária.

## Contract

Demanda: avaliar viabilidade de direcionar o treino NCM para o modelo
testado no colibri (Qwen3-Coder-Next 80B IQ1_M / 30B IQ2_M-topk6).

Scope in: factos sobre treinabilidade local; alternativas de uso do
LLM no pipeline NCM; custo/benefício; recomendação.
Scope out: implementar qualquer braço novo; parar o v5-ext em curso;
alterar pesos do LLM.

### Quality gates

- G1: toda afirmação de viabilidade com evidência (formato, RAM,
  compute medido no projeto).
- G2: nenhum braço novo iniciado sem decisão do usuário.

### Acceptance criteria

- T1 (sequencial): resposta factual — GGUF do colibri é treinável
  localmente? com evidência de formato/memória.
- T2 (sequencial, após T1): tabela de alternativas viáveis
  (corpus destilado, VQ sobre hidden states, teacher-student) com
  custo estimado em CPU commodity.
- T3 (sequencial, após T2): relatório em `.agentic/research/` +
  recomendação apresentada ao usuário.
