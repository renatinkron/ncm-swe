# RUN-038 — Task Plan

## Demand

Fazer o NCM participar do mecanismo de cartucho (pedido do user): o mesmo
knowledge pack (pack_regex, 24 cards gerados pelo 30B em RUN-037) alimenta
uma arquitetura completamente diferente — prova de portabilidade
cross-arquitetura do formato de conhecimento.

## Design

O LevelGenerator é incondicional por natureza (segmento 128 tokens a partir
de l0) — não há prompt→resposta. O teste honesto equivalente ao plug/unplug
é **deslocamento de distribuição por domínio**:

1. Pack cards → texto `probe\nideal_answer` → BPE oficial → pad/ctx128 →
   `vq.encode` → code rows (N,641).
2. BASELINE: `gen_ncm_v2/final.pt` gera 16 samples → decode → regex-score
   por texto (presença de indicadores: `\\d`, `\\w`, `[...]`, `re.`, `regex`,
   `^`/`$`, `{n,m}`; + tentativa re.compile do pattern extraído).
3. FT: AdamW lr=1e-4, ~30 epochs nos 24 code-rows via `gen.loss(idx)`
   (leve — não destruir o gerador).
4. PÓS-FT: 16 samples idênticos (mesma seed) → decode → regex-score.
5. Métricas: delta de regex-hits/segmento, padrões compiláveis, samples
   dumpados pra inspeção; CE de treino registrado.

Encoda pack→codes, baseline samples, FT leve, post samples, regex-scoring,

Roda no container; números reais no SESSION_HANDOFF + report (incl. negativo).

## Contract

**Scope in**: `scripts/ncm_packtrain.py`, `artifacts/ncm_packtrain/`, docs,
`.agentic/`.
**Scope out**: `vendor/`, `artifacts/gen_ncm_v2/` (read-only — FT roda numa
CÓPIA in-memory dos pesos; checkpoint original nunca sobrescrito),
`artifacts/codes_official`, pesos do tokenizer.

**Quality gates**:
- script roda via `podman run --rm -i --network none -v $PWD:/repo -w /repo
  localhost/lcm-infer python3 scripts/ncm_packtrain.py`
- checkpoint final.pt intocado (mtime/bytesize)
- `git diff --check`; status restrito ao scope

**Acceptance criteria**:
1. codes.npy com N≥20 linhas (641 col)
2. metrics.json: regex_score_pre, regex_score_post, compilable_pre/post,
   train_ce_first/last, n_samples
3. samples_pre/post.txt gravados pra inspeção qualitativa
4. docs com veredito honesto (inclui "não provou" se for o caso)
