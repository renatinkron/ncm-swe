# RUN-004 Task Plan — escalar para ~300M (o "melhor possível" real)

Per user demand + research/arch-eval: paper's own scale is 100–725M, never
billions. Billions is physically impossible here (RAM). The defensible CPU
ceiling for a trainable step-up is **~300M** — `configs/generator_300m.yaml`
(24×1024, GQA 16q/4kv, SwiGLU 5504) created.

## Tasks

### T001 — Launch 300M NCM training, measure viability

**Intent**: `train_generator.py --model ncm --config configs/generator_300m.yaml
--out artifacts/gen_ncm_300m --steps 2000`. Measure: params count, RAM peak,
s/step. If step cost >~90s or RSS pushes swap, downgrade to batch 4.
**Domain**: ml | **Risk**: medium | **Deps**: []
**Acceptance**: process alive, params ~300M logged, first losses descend,
RAM within 23GB, no OOM.

### T002 — Launch 300M AR baseline (comparable arm)

**Intent**: same config, `--model ar --out artifacts/gen_ar_300m`. Sequential
after NCM start (measure first to keep RAM safe) or accept contention.
**Domain**: ml | **Risk**: medium | **Deps**: [T001]

**Domain**: ml | **Risk**: low | **Deps**: [T002]
**Acceptance**: `bench_300m.json` exists; honest comparison in report.
