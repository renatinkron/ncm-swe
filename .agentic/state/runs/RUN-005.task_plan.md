# RUN-005 Task Plan — "Pirâmide sobre tronco congelado" (MoE→NCM em CPU)

Pesquisa completa: `.agentic/research/moe-to-ncm-conversion.md` + RAG em
`.agentic/research/rag/`. Síntese: codebook-pirâmide derivado dos embeddings
do Qwen (sem VQ-VAE) + cabeças-de-nível sobre backbone congelado + knob de
resolução adaptativo. Phase A (barata) é o gate de viabilidade.

## Branch Strategy

- decision: `current_branch` (`main`).

## Phases

- Phase 1: T001 | Phase 2: T002 | Phase 3: T003

## Tasks

### T001 — Codebook-pirâmide dos embeddings Qwen + medida de fidelidade

**Intent**: script `scripts/build_pyramid_codebook.py`: carrega matriz de
embeddings do Qwen-0.6B (GGUF local ou HF), aplica MiniMSRQ L=6 níveis sobre
as linhas V×d, salva `artifacts/pyramid_cb.pt`. Métricas: erro de recon por
nível, códigos vivos por nível, top-1 token recovery (decode pirâmide→token
exato via argmin sobre código somado).
**Domain**: ml | **Risk**: medium | **Deps**: []
**Acceptance**: recon err nível-0 >> nível-5 (pirâmide real); ≥50% top-1
token recovery no nível final; nenhum nível com 1 código só (sem colapso).

### T002 — Cabeças-de-nível sobre backbone congelado (treino CPU)

**Intent**: `scripts/train_level_heads.py`: Qwen-0.6B congelado; L cabeças
lineares+condicionamento prevendo códigos da pirâmide sobre o corpus
(tokenizado BPE do Qwen); treina só cabeças (~<100M). Baseline loss < uniforme
por nível + curva coarse-first.
**Domain**: ml | **Risk**: medium | **Deps**: [T001]
**Acceptance**: loss nível-0 < 60% do uniforme após treino; ckpt salvo.

### T003 — Protótipo de inferência adaptativa + bench honesto

**Intent**: `scripts/decode_pyramid.py`: gera texto via pirâmide com early-exit
por entropia (nível k→k+1 só se incerto) vs profundidade fixa; mede
tok/s + qualidade vs AR puro do mesmo backbone. Documentar em report.md.
**Domain**: ml | **Risk**: medium | **Deps**: [T002]
**Acceptance**: `artifacts/pyramid_bench.json` com tok/s por profundidade e
delta de qualidade; resultado negativo também registrado.
